## ✨ Key Features
- **Modular backend architecture** on Next.js 15 + Express, built to handle high-concurrency academic data requests
- **Optimized database reliability** via MongoDB compound indexing and connection pool limits — stable performance for **500+ users**
- **Google Generative AI integration** to auto-generate data-driven backend insights and student performance reports
- Actively used and maintained with collaborator **[@dilip27m](https://github.com/dilip27m)**

## 🛠️ Getting Started

```bash
git clone https://github.com/subhash865/<repo-name>.git
cd <repo-name>
npm install
```

Create a `.env.local`:

```
MONGODB_URI=your_mongo_uri
GOOGLE_GENAI_API_KEY=your_google_ai_key
```

Run locally:

```bash
npm run dev
```
